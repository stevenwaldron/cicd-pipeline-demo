# CICD Pipeline Demo

A simple static website used to test the custom CICD-create AWS deployment toolkit.

## Purpose

This project is intentionally simple so the CI/CD pipeline itself can be tested.

## Pipeline Test

1. Push the project to GitHub.
2. Create the AWS CI/CD pipeline.
3. Deploy the application.
4. Verify the website.
5. Change the application.
6. Commit and push the change.
7. Verify the pipeline automatically deploys the new version.

Current version: 1.0.0
